# SteelSeries Assist 0.0.5

发布日期：2026-09-03

这是 SteelSeries Assist 的第五个 Windows x64 自包含便携版本，新增 Sonar EQ 快速选择，并针对大型游戏 EQ 目录优化了下拉菜单性能。

## 使用方法

1. 安装并启动 SteelSeries GG，确认 Sonar 已启用；
2. 解压 `SteelSeriesAssist-0.0.5-win-x64.zip`；
3. 运行 `SteelSeriesAssist.exe`；
4. 单击系统托盘图标打开控制面板，右键图标可退出。

发布包已包含 .NET 8 运行时，无需额外安装 .NET。

## 本次更新

- 每个 Sonar 通道可快速选择对应的 EQ；
- 收藏 EQ 位于列表顶部，普通 EQ 可通过搜索框查找；
- 默认只加载少量普通 EQ，滚动到列表底部会逐批加载更多，改善大量游戏 EQ 时的操作流畅度；
- 打开菜单时当前 EQ 会定位在可视区域中央；向上或向下滚动均可继续逐批加载普通 EQ；
- 首屏仅显示 Sonar 当前已选 EQ；首次打开某通道的菜单时会显示“正在加载 EQ…”，并只读取该通道的完整目录；
- EQ 预设按通道缓存，Game 的大型目录不会阻塞其他通道或面板首屏；
- Assist 会回读 Sonar 的当前选中配置，确认 EQ 切换已实际生效。

## 注意事项

- 在 Assist 中切换 EQ 后，Sonar 的实际配置会更新；但已打开的 SteelSeries GG 页面可能不会立即刷新自己的 EQ 显示；
- 当前在 SteelSeries GG 116.0.0 / Sonar 1.99.0 上完成验证；
- 发布文件尚未代码签名，Windows 可能提示未知发布者；
- 当前提供便携压缩包，尚无安装器。
