# SteelSeries Assist 0.0.6

发布日期：2026-09-05

这是 SteelSeries Assist 的第六个 Windows x64 自包含便携版本，修复 GG 外部操作后 EQ 下拉列表被错误缩减的问题。

## 使用方法

1. 安装并启动 SteelSeries GG，确认 Sonar 已启用；
2. 解压 `SteelSeriesAssist-0.0.6-win-x64.zip`；
3. 运行 `SteelSeriesAssist.exe`；
4. 单击系统托盘图标打开控制面板，右键图标可退出。

发布包已包含 .NET 8 运行时，无需额外安装 .NET。

## 本次更新

- 修复在 GG 中增加、减少或切换 EQ 后，Assist 的下拉列表可能只剩当前 EQ 一项的问题；
- 修复执行应用路由后，后台状态刷新可能覆盖已加载 EQ 目录的问题；
- 已加载的通道 EQ 目录会保留；若 GG 新建了当前正在使用的 EQ，下一次打开该通道菜单会自动重新加载完整目录。
- 已加载通道再次打开菜单时会立即显示缓存列表，同时在后台复核 Sonar 目录，自动同步 GG 中 EQ 的新增、删除和收藏状态变化。

## 注意事项

- 在 Assist 中切换 EQ 后，Sonar 的实际配置会更新；但已打开的 SteelSeries GG 页面可能不会立即刷新自己的 EQ 显示；
- 当前在 SteelSeries GG 116.0.0 / Sonar 1.99.0 上完成验证；
- 发布文件尚未代码签名，Windows 可能提示未知发布者；
- 当前提供便携压缩包，尚无安装器。
