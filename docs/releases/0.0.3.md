# SteelSeries Assist 0.0.3

发布日期：2026-08-01

这是 SteelSeries Assist 的第三个 Windows x64 自包含便携版本，重点改进 Assist、SteelSeries GG / Sonar 和键盘媒体键之间的实时音量同步。

## 使用方法

1. 安装并启动 SteelSeries GG，确认 Sonar 已启用；
2. 解压 `SteelSeriesAssist-0.0.3-win-x64.zip`；
3. 运行 `SteelSeriesAssist.exe`；
4. 单击系统托盘图标打开控制面板，右键图标可退出。

发布包已包含 .NET 8 运行时，无需额外安装 .NET。

## 本次更新

- 通过 Sonar WebSocket 实时接收 GG、键盘媒体键和其他来源的音量与静音变化；
- Assist 调整 Game、Chat、Media、Aux、Mic 时，GG 页面能够同步更新；
- 连续拖动滑块时采用每通道节流和最终值提交，避免请求堆积；
- WebSocket 自动重连，不可用时降级为 HTTP 音量轮询；
- 音量更新不再重建滑块、下拉框或应用路由控件；
- 自动测试增加至 9 项。

## 注意事项

- 当前在 SteelSeries GG 116.0.0 / Sonar 1.99.0 上完成验证；
- Master 没有对应的 Windows 虚拟端点，Assist 修改 Master 时已打开的 GG 页面可能不会立即刷新；
- 发布文件尚未代码签名，Windows 可能提示未知发布者；
- 当前提供便携压缩包，尚无安装器。
