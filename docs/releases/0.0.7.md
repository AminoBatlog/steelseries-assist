# SteelSeries Assist 0.0.7

发布日期：2026-11-04

本版本增加聊天混音和可选开机启动，并改进托盘面板、显示器适配和后台资源管理。

## 使用方法

1. 安装并启动 SteelSeries GG，确认 Sonar 已启用；
2. 下载并解压 `SteelSeriesAssist-0.0.7-win-x64.zip`；
3. 运行 `SteelSeriesAssist.exe`；
4. 单击系统托盘图标打开控制面板，右键图标可设置开机启动或退出程序。

发布包已包含 .NET 8 运行时，无需额外安装 .NET。

从旧版升级时，请先从托盘退出旧版，再解压并启动新版。若已启用开机启动，移动程序目录后请在新版托盘菜单中重新勾选，以更新启动路径。

## 本次更新

- 新增聊天混音（ChatMix）：向左偏游戏、向右偏聊天，支持中心吸附和一键恢复均衡；写入后回读确认，并通过事件和定期读取同步状态；
- 兼容新版与旧版 ChatMix 接口；由耳机旋钮控制、游戏与聊天输出设备不匹配等情况下显示原因并禁止调节；
- 托盘菜单新增“开机启动”，默认关闭，启用后登录 Windows 即可静默驻留托盘；
- Media/Aux 按实际启用的 Sonar 虚拟输出设备显示；
- 扩展面板空间，采用统一的深色标题区和关闭按钮，右上角关闭仍收起到托盘；
- 按鼠标所在显示器的工作区定位，增加每显示器 DPI 适配；
- 改进 WebSocket 连接生命周期，限制消息大小和未完成分片等待时间；
- 合并后台事件与界面更新，完善退出和 ChatMix 端点切换时的任务取消与资源释放；
- 自动测试扩展至 25 项。

## 注意事项

- 当前主要适配 SteelSeries GG 116.0.0 / Sonar 1.99.0；ChatMix 听感、GG 双向交互、长时间运行、休眠唤醒及混合 DPI 多屏场景仍需进一步验证；
- 在 Assist 中切换 EQ 后，Sonar 的实际配置会更新，但已打开的 GG 页面可能不会立即刷新显示；
- 发布文件尚未代码签名，Windows 可能提示未知发布者；
- 当前提供 Windows x64 便携压缩包，尚无安装器；
- 同时提供 `.sha256` 文件，用于校验下载的压缩包。
