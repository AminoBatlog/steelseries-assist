# SteelSeries Assist 0.0.2

发布日期：2026-08-01

这是 SteelSeries Assist 的第二个 Windows x64 自包含便携版本。

## 使用方法

1. 安装并启动 SteelSeries GG，确认 Sonar 已启用；
2. 解压 `SteelSeriesAssist-0.0.2-win-x64.zip`；
3. 运行 `SteelSeriesAssist.exe`；
4. 单击系统托盘中的三路推子图标打开控制面板，右键图标可退出。

发布包已包含 .NET 8 运行时，无需额外安装 .NET。

## 本次更新

- 使用现代化喇叭图标替代旧式文字静音按钮；
- 静音时叠加红色斜线，并显示暗红状态背景；
- 修复 Windows 可执行文件图标格式；
- 在资源管理器、窗口标题栏、任务管理器和启动项中使用正式图标。

## 注意事项

- 当前在 SteelSeries GG 116.0.0 上完成验证；
- 发布文件尚未代码签名，Windows 可能提示未知发布者；
- 应用路由按进程设置，部分程序需要重启或重新创建音频会话后才会完全切换；
- 当前提供便携压缩包，尚无安装器。
