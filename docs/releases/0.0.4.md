# SteelSeries Assist 0.0.4

发布日期：2026-08-04

这是 SteelSeries Assist 的第四个 Windows x64 自包含便携版本，重点改进音量、静音和滑块之间的交互一致性。

## 使用方法

1. 安装并启动 SteelSeries GG，确认 Sonar 已启用；
2. 解压 `SteelSeriesAssist-0.0.4-win-x64.zip`；
3. 运行 `SteelSeriesAssist.exe`；
4. 单击系统托盘图标打开控制面板，右键图标可退出。

发布包已包含 .NET 8 运行时，无需额外安装 .NET。

## 本次更新

- 音量拖到 0% 时自动静音；
- 音量从 0% 调高时自动取消静音；
- 点击静音按钮会将对应通道音量设为 0%；
- 再次点击静音按钮会恢复该通道最近一次非零音量；
- 后台状态刷新不会覆盖记忆的上次音量；
- 单击音量轨道任意位置时，滑块会直接跳转到对应音量。

## 注意事项

- 当前在 SteelSeries GG 116.0.0 / Sonar 1.99.0 上完成验证；
- 发布文件尚未代码签名，Windows 可能提示未知发布者；
- 当前提供便携压缩包，尚无安装器。
