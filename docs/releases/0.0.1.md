# SteelSeries Assist 0.0.1

发布日期：2026-08-01

这是 SteelSeries Assist 的第一个便携版本，面向 Windows x64 和 SteelSeries GG / Sonar 用户。

## 使用方法

1. 安装并启动 SteelSeries GG，确认 Sonar 已启用；
2. 解压 `SteelSeriesAssist-0.0.1-win-x64.zip`；
3. 运行 `SteelSeriesAssist.exe`；
4. 单击系统托盘中的三路推子图标打开控制面板，右键图标可退出。

发布包已经包含 .NET 8 运行时，无需额外安装 .NET。应用不会创建或处理虚拟声卡，只调用本机 Sonar 服务读取和修改 GG 设置。

## 首版功能

- Master、Game、Chat、Media、Aux、Mic 音量与静音；
- Sonar 通道的物理设备绑定切换；
- 按虚拟声卡分区显示应用路由；
- 拖放应用到 Game、Chat、Media 或 Aux；
- 多音轨应用状态展示；
- GG / Sonar 状态轮询同步和重连；
- Windows 系统托盘常驻及单实例保护。

## 注意事项

- 当前在 SteelSeries GG 116.0.0 上完成验证；
- 发布文件尚未代码签名，Windows 可能提示未知发布者；
- 如果应用路由没有立即完全变化，请重启目标应用或让它重新创建音频会话；
- 已知限制请参阅项目根目录的 `CHANGELOG.md` 和 `STATUS.md`。
